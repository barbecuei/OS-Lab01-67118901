3. Analysis (The GIL):
การทำ Multithreading ไม่ได้ช่วยให้โค้ดทำงานเร็วขึ้นเพราะโปรแกรม Python มีข้อจำกัดที่เรียกว่า Global Interpreter Lock (GIL) ซึ่ง GIL จะคอยล็อกไม่ให้ Thread หลายตัวประมวลผลคำสั่งของ Python พร้อมกันได้ ทำให้ไม่สามารถทำงานแบบขนาน (Parallel) บน CPU หลาย Core ได้จริงในงานที่ต้องคำนวณหนักๆ (CPU-bound)

ส่วน Multiprocessing เป็นทางเลือกที่ดีกว่ามากสำหรับงานที่ใช้ CPU หนักๆ อย่างเช่นการทำ Data Augmentation ใน Machine Learning เพราะแต่ละโปรเซสจะมีพื้นที่หน่วยความจำ (Memory Space) และ GIL เป็นของตัวเองอย่างอิสระ ทำให้สามารถทะลวงขีดจำกัดของ GIL และเปิดโอกาสให้ระบบปฏิบัติการกระจายงานไปประมวลผลแบบขนานบน CPU ทุก Core ได้อย่างแท้จริง
