2. POSIX Permissions:

ผมจะกำหนดสิทธิ์ไฟล์เป็น 0o750 โดย Owner มีสิทธิ์ Read, Write และ Execute รวมเป็น 4+2+1 = 7 ส่วน Group มีสิทธิ์ Read และ Execute รวมเป็น 4+1 = 5 และ Others ไม่มีสิทธิ์ใด ๆ จึงมีค่าเป็น 0
ดังนั้นคำสั่งที่ใช้ใน Python คือ os.chmod(filename, 0o750) ซึ่งจะทำให้สิทธิ์ของไฟล์เป็น -rwxr-x--- โดย Owner สามารถอ่าน เขียน และเรียกใช้งานไฟล์ได้ Group สามารถอ่านและเรียกใช้งานได้ ส่วน Others ไม่สามารถเข้าถึงไฟล์ผ่านสิทธิ์ปกติได้


3. The AI Context:

จากการทดลอง ผมพบว่าเมื่อกำหนดสิทธิ์ไฟล์ Model Weights เป็น 0o444 แล้วโปรแกรมพยายามเปิดไฟล์ในโหมดเขียน ระบบปฏิบัติการจะปฏิเสธการเขียน ทำให้ไฟล์โมเดลไม่ถูกเขียนทับในการทดลองนี้
ผมเข้าใจว่าการใช้ OS File Permissions ปลอดภัยกว่าการตรวจสอบด้วยโค้ด Python เพียงอย่างเดียว เพราะระบบปฏิบัติการเป็นผู้บังคับใช้สิทธิ์ในการเข้าถึงไฟล์ หากโปรเซสไม่มีสิทธิ์เขียน ระบบจะปฏิเสธคำสั่ง แม้โปรแกรมจะมีข้อผิดพลาดหรือพยายามเปิดไฟล์ในโหมดเขียนก็ตาม
ส่วน Python try-except เป็นเพียงการจัดการข้อผิดพลาดที่เกิดขึ้น ไม่ได้ป้องกันการเขียนไฟล์ด้วยตัวเอง ดังนั้นการกำหนดสิทธิ์ไฟล์ในระดับ OS จึงช่วยลดความเสี่ยงที่โปรแกรมอื่นหรือสคริปต์เทรน AI จะเขียนทับ Model Weights โดยไม่ได้ตั้งใจ
