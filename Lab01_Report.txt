1. Hardware Baseline:
- OS Version: Linux 6.8.0-1052-azure
- Number of CPU Cores: 2
- Total RAM: 7.76 GB

2. Observation (from htop during stress test):
ในระหว่างการทดสอบการทำงานหนักของ CPU สคริปต์ Python ไม่ได้ใช้งาน CPU ครบ 100% ทุก Core แต่จะใช้งานหนักแค่ Core เดียวเท่านั้น จากหน้าต่าง htop สังเกตเห็นว่าการใช้งานของ Core 1 พุ่งสูงขึ้นไปเกือบ 90-100% ในขณะที่ Core 0 มีการใช้งานที่ค่อนข้างต่ำ เหตุผลที่เป็นแบบนี้เพราะการทำงานมาตรฐานของ Python จะประมวลผลตามลำดับแบบ Single-thread (ทำงานเส้นทางเดียว) ซึ่งจำกัดการทำงานให้อยู่บน CPU แค่ Core เดียวเท่านั้น

3. Analysis:
เมื่อต้องทำงานกับชุดข้อมูลขนาดใหญ่เช่น รูปภาพ 500,000 รูป การรู้ขีดจำกัดของระบบเป็นเรื่องสำคัญมากด้วยเหตุผล 2 ประการ:
- ขีดจำกัดของ RAM: เราไม่สามารถโหลดรูปภาพ 500,000 รูปเข้าไปใน RAM ขนาด 7.76 GB ได้พร้อมกันทั้งหมดในคราวเดียว หากพยายามทำเช่นนั้น OS จะเกิดภาวะหน่วยความจำเต็ม (Out of Memory - OOM) และบังคับปิดโปรแกรม การรู้ลิมิตนี้ทำให้เราสามารถเขียนโค้ดเพื่อแบ่งโหลดรูปภาพเข้ามาทีละส่วน (Batches) ได้
- จำนวน CPU Core: การรู้ว่าระบบมี CPU 2 Core ทำให้ทราบว่าหากเราเขียนโค้ด Python แบบ Single-thread ธรรมดา เราจะสูญเสียพลังการประมวลผลไปครึ่งหนึ่งฟรีๆ เราสามารถนำข้อมูลนี้ไปใช้ออกแบบการเขียนโค้ดแบบประมวลผลขนาน (Multiprocessing) เพื่อดึงประสิทธิภาพของทุก Core มาช่วยเร่งความเร็วในการเตรียมข้อมูลได้
